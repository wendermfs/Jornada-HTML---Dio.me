Estrutura de Html:

  1. Tag: Html => Essa tag pelo que parece é todo o mwu documento de html dentro dele
  2. Tag: Head => Dento do Head fica todo conteúdo sera carregado par a pagina
  3. Tag: Body => dentro dessa Tag ficara tudo que aparecera e interagira com o usuário/utilizado.

Atributos:

Atributos são as propriedades de nossas TAGS são eles que nos garantem que podemos manipular nossa tags.

Ex: ID, Style, Class e etc existem também atributos que são próprios para serem utilizados em uma Tag especifica, nesse caso o nosso Type que é próprio para a nossa TAG Input logo também sera preciso passar como voce quer trabalhar ou seja com que tipo de atributo voce quer trabalhar dentro da TAG Input.

Textos:

Como estruturamos os textos dentro de um Web site? Podemos utilizar algumas TAGS que nos ajudaram com esses textos, para que saibamos por exemplo qual o assunto que estamos tratando em determinado documento que estivermos elaborando por exemplo um BLOG la temos que separa o assunto do conteúdo e fazemos isso sendo representados por níveis de textos que são eles: as TAGS h1 h2 h3 h4 h5 h6 e a tag p, e todas elas são utilizadas pela representação de dois elementos entre elas que são : <>

Tags para Auxiliar na formatação do seus textos:

  • A TAG i :formata a letra ou a palavra em itálico.
  • A TAG strong :formata a letra ou a palava em negrito.
  • A TAG u :formata a letra ou a palavra e a deixa sublinhada.
  • A TAG Mark :formata a letra ou palavra e a deixa como se fosse uma marca texto.
  • A TAG Sup :formata a letra ou a palavra a deixando como se fosse uma potenciação ou seja na parte superior.

Listas

Podemos fazer uma lista de duas formas se precisarmos delas em nosso documentos. São elas as Lista Ordenada que é uam lista na qual a medida das linhas que voce for inserindo ela vai numerando cada linha mostrando que existe uma ordem definida. e também a Lista não ordenada que é uma lista no qual ela nao deixa de ser ordenada mas nao é definida elas só são representadas por Bolas a frente de cada linha da lista. Essa é a definição de como essas lista ficam representadas. E quando são representadas em HTML para as listas ordenadas utilizamos as TAGS OL que são para as listas Ordenadas e Ul que são para as listas não ordenadas,também não se esqueçam de representá-las através duas setas como mencionei acima.


Agora vamos passar para a outra parte que é como você escreve essas lista pois não basta somente representa-lás mais voce também as deve informar quais são os intens que estão de acordo com cada lista e para isso utilizamos para cada item as tags Li que vão representa cada item da sua lista.
